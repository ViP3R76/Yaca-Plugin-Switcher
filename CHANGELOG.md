## 1.0.0 – Stable .NET 10 baseline

- Stable validated YACA Plugin Switcher baseline.
- Automated Windows x64 single-file release packaging.
- Tagged releases receive a user-ready ZIP and SHA-256 checksum.
- Portable configuration, logs and backups beside the executable.
- Fixed three-day log retention.
- English/German localization with Windows-language detection.
- Backup management with optional individual deletion.
- Dark-mode UI and embedded branding.

Future UI redesign work should be developed separately from this stable baseline.
